# 旧脚本迁移说明

为了保证历史脚本在迁移期间可以继续工作，仓库保留了根目录兼容入口；同时，新的业务逻辑与脚本应尽快迁移到以下目录：

- `app/`
- `scripts/`
- `tools/`
- `packaging/`

迁移原则：

1. 根目录只保留最小入口脚本
2. 真正代码不再放在根目录
3. 新增功能统一放在标准工程目录
4. 旧文件在必要时保留为兼容层，而非主工作目录

历史入口：

- `build_java.bat`
- `gen_baseline.ps1`
- `一键打包.bat`

推荐的长期状态：

- 仅保留根目录文档和兼容入口
- 业务实现全部落到新目录结构中
